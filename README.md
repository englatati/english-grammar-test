# english-grammar-test

Адаптивный статический тест из 50 вопросов для предварительной диагностики **грамматики** английского. HTML, CSS и JavaScript без зависимостей, сборки, backend и регистрации. Вопросы и ключ перенесены из задания; в №6, №28 и №45 уточнены контекст и варианты ответа (см. ниже).

## Запуск

Из каталога репозитория:

```sh
sh scripts/serve.sh
```

Откройте сайт через HTTP на порту 8000. Открытие `index.html` через `file://` не подходит для JavaScript-модулей. Перезапуск страницы сбрасывает ответы. Установка npm-пакетов не требуется.

Для запуска в облачной среде независимо от терминальной сессии:

```sh
nohup sh scripts/serve.sh >/tmp/english-grammar-test-server.log 2>&1 </dev/null &
curl --fail http://127.0.0.1:8000/
```

Preview должен использовать порт **8000**. Другой порт можно задать через `PORT=3000 sh scripts/serve.sh`. Сервер слушает `0.0.0.0`, чтобы принимать запросы от прокси среды. Если порт занят, сначала проверьте ответ сервера; не запускайте второй процесс поверх первого. Лог фонового сервера находится в `/tmp/english-grammar-test-server.log`. После восстановления среды процесс нужно запустить заново.

## Публикация

- **GitHub Pages:** Settings → Pages → Deploy from a branch, выбрать ветку с проектом и `/ (root)`.
- **Netlify:** опубликовать корневой каталог проекта, без команды сборки.
- **Vercel:** Framework Preset → Other, без команды сборки, Output Directory → `.`.

Все пути относительные, поэтому сайт работает и в подпапке GitHub Pages. Сервер должен отдавать `.js` с корректным JavaScript MIME-типом. Домен и публичная публикация настраиваются на выбранном хостинге.

## Структура

- `index.html`, `styles.css` — семантический интерфейс и адаптивный дизайн.
- `questions.js` — вопросы, четыре варианта и индекс правильного ответа.
- `scoring.js` — подсчёт по четырём блокам и выбор самого высокого доступного уровня.
- `results.js` — расшифровки уровней.
- `app.js` — навигация, выбор ответа, результат и полный сброс.

Ответы находятся только в памяти текущей вкладки. Нет cookies, аналитики, внешних шрифтов, запросов к API или постоянного хранилища. Ключ не отображается в интерфейсе, но доступен в исходниках: у статического клиентского теста его невозможно скрыть от просмотра кода.

## Проверки

```sh
node --test tests/scoring.test.mjs
# При работающем локальном сервере; требуется Python Playwright и /usr/bin/chromium:
python3 tests/browser.py
```

Тесты сверяют все 50 ключей с актуальным диагностическим ключом, фиксируют контекст и варианты №6, №28 и №45 и проверяют начисление балла за каждый из четырёх вариантов этих вопросов. Сохранены проверки всех 30 976 комбинаций баллов блоков и запрета повышения при проваленной базе.

Браузерный сценарий на ширинах 320, 390 и 1440 px проверяет клавиатуру, запрет перехода без ответа, возврат, три полных прохода (всё верно, всё неверно, ошибки только в №6/28/45), результат и сброс. Для исправленных вопросов проверяются текст задания, выбранный и правильный ответы в списке ошибок, баллы `[9, 15, 14, 9]` и текст результата для преподавателя. Копирование проверяется через перехват `clipboard.writeText` и резервного `execCommand('copy')`; это проверка передаваемого текста, а не системного буфера обмена. Также проверяется отсутствие внешних запросов, cookies и browser storage.

## Ограничения диагностического материала

### Уточнение №6, №28 и №45

У этих вопросов добавлен контекст, позволяющий выбрать один ответ из предложенных в стандартном английском. Количество вопросов, их порядок и распределение по блокам сохранены.

| № | Формулировка | A / B / C / D | Ключ |
| --- | --- | --- | --- |
| 6 | In your current job, ___ you work from home every day? | Are / Do / Does / Is | **B — Do** (индекс 1) |
| 28 | She started studying English three years ago and is still learning it today. She ___ English ever since. | studied / is studying / has been studying / had studied | **C — has been studying** (индекс 2) |
| 45 | They've been in the kitchen with me all evening, and we're still chatting. They ___ gone to bed yet. | must have / should / can't have / can't | **C — can't have** (индекс 2) |

- **№6:** текущая работа и ежедневная привычка задают Present Simple; `Did` заменён на `Is`, чтобы прошедшее время не оставалось альтернативой. Проверяется вопрос с `do` при подлежащем `you`.
- **№28:** учёба началась три года назад и продолжается сейчас; `ever since` связывает начало с настоящим. `studied` описывало бы завершённый период, `is studying` не выражает длительность с прошлого до настоящего, а для `had studied` нужна точка отсчёта в прошлом. Правильный вариант перенесён с A на C.
- **№45:** говорящий находится с этими людьми на кухне весь вечер и продолжает разговаривать с ними; это основание отрицать, что они уже легли спать. Включённый свет больше не служит доказательством. Проверяется отрицательный вывод о прошлом `can't have + V3`; правильный вариант перенесён с B на C.

В `questions.js` изменены только эти три объекта. В `tests/scoring.test.mjs` обновлён независимый ключ: B1-блок `ABCCABBBBCBBBAC`, B2-блок `BABBCBBAAB`; ключ №6 остаётся B. Автоматические проверки защищают данные и расчёт, но не заменяют преподавательскую оценку языкового контекста остальных заданий.

Пороговые условия также сохранены буквально: A2+ присваивается только при 8–9 баллах B1, B1+ — только при 5–6 баллах B2. Поэтому повышение балла сложного блока без выполнения всех условий следующего уровня может убрать знак «+». Это предусмотрено заданными правилами, а не вычислительная ошибка.
